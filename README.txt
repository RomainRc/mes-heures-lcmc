- tableau de bord compact et riche
- calendrier visible dès l'accueil
- dernières journées

- saisie matin + après-midi
- modification d'une journée
- export CSV
- PWA/offline + cache version 8.1

INSTALLATION GITHUB PAGES
1. Décompresse tout le ZIP.
2. Mets TOUS les fichiers à la racine du dépôt GitHub Pages.
3. Vérifie surtout que lcmc-hero.jpg est bien à côté de index.html.
4. Attends la publication GitHub Pages.
5. Si une ancienne version reste affichée : ouvre le site en navigation privée une fois, ou supprime/réinstalle l'application depuis l'écran d'accueil.

Les données d'heures/exploitations restent dans le stockage local du navigateur via les clés LCMC existantes.
